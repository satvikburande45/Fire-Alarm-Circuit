# Temperature-Based Fire Alarm Circuit Using 555 Timer

A temperature-based fire alarm circuit using a 555 timer IC and an NTC thermistor to detect rising temperature and activate an alarm when the set threshold is reached.

## Project Overview
This project demonstrates a basic electronic fire alarm system that responds to temperature changes. An NTC thermistor acts as the temperature-sensing element, while a 555 timer IC is used in the alarm control circuit. When the temperature reaches the configured threshold, the circuit activates an alarm to indicate a potential overheating or fire condition.

## Objectives
- Understand temperature sensing using an NTC thermistor.
- Learn the application of the 555 timer IC in alarm circuits.
- Design a basic temperature-triggered warning system.
- Understand sensor interfacing and electronic circuit operation.

## Components Used
- 555 Timer IC
- NTC Thermistor
- Resistors
- Capacitors
- Buzzer or alarm indicator
- Connecting wires
- Power supply
- Breadboard or PCB, depending on implementation

## Working Principle
1. The NTC thermistor senses changes in temperature. Its resistance decreases as temperature increases.
2. The sensing circuit responds to the resistance change.
3. When the temperature reaches the configured threshold, the circuit triggers the 555 timer-based alarm.
4. The buzzer or alarm indicator activates to provide a warning.

**Temperature Sensing → Threshold Detection → 555 Timer Circuit → Alarm Output**

This is an educational prototype and should not be considered a certified fire-detection or life-safety system. A practical installation requires a properly tested and approved fire alarm device.
